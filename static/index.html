Laporan penjualan — basis akrual

Semua angka diakui di bulan order dibuat; potongan & refund dari laporan penghasilan dipasangkan ke order-nya. Order yang dananya dikembalikan penuh = retur, keluar dari bruto walau status non-batal. Potongan ditampilkan positif (sudah dibalik tandanya).

Produk — bruto terjual & batal

Semua produk, urut bruto non-batal pada periode terpilih. Klik ▸ di nama produk untuk membuka varian (warna/ukuran). Order terjual = order unik: di baris produk satu order dihitung sekali walau berisi beberapa warna, di baris varian order yang sama bisa muncul di beberapa warna — jadi jumlah order varian bisa lebih besar dari produknya; bandingkan varian pakai qty dan bruto. Excel berisi semua produk + sheet per varian, mengikuti filter di atas.

Master HPP — toko …

Pakai kolom:
Item manual tetap tersimpan walau sheet diimpor ulang; nama yang sama dengan sheet → item manual yang dipakai.

Pemetaan listing → item HPP — toko …

Urutan pencocokan: (1) kode SKU listing = kolom Kode di master (bundle "A+B" = jumlah HPP komponen), (2) pilihan manual, (3) nama model di nama listing (Runa, Rumi, …). Yang belum ketemu ada di paling atas — pilih manual per listing/SKU. Pilih "— tanpa HPP —" kalau memang sengaja. Setelah ubah, klik Hitung lagi di atas.

Biaya iklan per bulan — toko …

Input manual, bisa diedit langsung di sel. Baris atribusi menentukan iklan channel itu dibebankan ke penjualan platform mana (dipakai saat filter platform Shopee / TikTok; filter Gabungan memakai semua). Setelah ubah, klik Simpan lalu Hitung.
ACR = total iklan / peredaran bruto riil. Breakeven iklan: GPM harus lebih besar dari ACR. Laba setelah iklan = laba setelah marketplace − iklan (masih sebelum opex/gaji).

Audit data penjualan

Memeriksa 4 hal: (1) kelengkapan file per bulan, (2) rekonsiliasi hasil hitung vs total resmi di ringkasan laporan penghasilan platform, (3) anomali per order, (4) jejak satu order. Ikut filter toko & rentang bulan di atas.

1 · Kelengkapan data per bulan

Hari kosong = tanggal tanpa satu pun order padahal bulan itu ada file pesanan (indikasi export tidak menutup seluruh bulan). Settle % = porsi bruto yang sudah ada di laporan penghasilan.

2 · Rekonsiliasi vs total resmi platform

Per file laporan penghasilan: angka di sheet ringkasan resmi (Summary / Laporan) dibandingkan dengan jumlah rincian per order yang dibaca app. Selisih ≠ 0 berarti ada baris yang tidak terbaca atau platform sendiri tidak konsisten.

3 · Temuan per order

Klik judul temuan untuk melihat daftar ordernya (maks. 300 baris; lengkapnya di Excel audit).

4 · Jejak order

Masukkan No. Pesanan / Order ID untuk melihat semua baris sumbernya di tiap file dan bagaimana order itu dihitung.
